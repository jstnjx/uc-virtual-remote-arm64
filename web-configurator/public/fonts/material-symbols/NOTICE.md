# Material Symbols Sharp

This directory contains the locally hosted Material Symbols Sharp variable font used by the Unfolded.Tools Web Configurator community build.

Material Symbols are provided by Google under the Apache License, Version 2.0. The complete license text is included in `LICENSE.txt`.

The font replaces the Font Awesome runtime dependency used by the published 2.3.3 source snapshot. The deployed build uses the `FILL`, `GRAD`, `opsz`, and `wght` variable axes with weights 100, 300, and 400.
